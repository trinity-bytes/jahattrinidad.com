## 3. Patterns

- **Page shortcuts don't know about state (HI-01, HI-02, HI-15).** The lens `keydown` handler and `switchTo` run whatever the page is doing: during a reveal, inside a text field, mid-conversation. One guard in `Lens.astro` (no switch while `root.dataset.lensReveal` is set or while focus is in `EDITABLE`, for both `I` and `Esc`) closes all three.
- **Annotations have no lifecycle or minimum (HI-03, HI-04, HI-12, HI-16, HI-17).** `Annotation.astro` is placed by coordinates and styled by the design.md v3.3 opacities. It needs a contrast floor (note ≥ 60 %), one size (12 px), one label-to-leader rule for all four sides, a gutter clamp for small pins, and a rule to hide when its target changes state (the open chat).
- **Lens tokens without an Inside check (HI-06, HI-07).** `--color-bg` and `--color-card-raised` both resolve to green-950 Inside, so anything that uses one as the hover of the other vanishes; the Contact marker took green-200 where siblings take green-300. A two-column token table (Outside / Inside) checked for pairs that collapse would catch both.
- **Chat card built from loose values (HI-08, HI-09, HI-10).** 18 vs 16 px insets, 44 vs 46 px pills, 36 px pencils, two label cases. One spacing value (16), one control height (44), one label style for the card.
- **Area 1 patterns that also hold here**: no link component (HO-01, HO-14), no section-header component (HO-02, HO-17), state tokens missing (HO-05, HO-06, HO-18), icon stroke tied to size (HO-12).

## 5. Strengths

- **Focus handoff in the lens and the chat is right.** Enter on the lens switches and moves focus to "Back outside" (and back), the live region announces the new state, focus returns to the composer after each reply and lands on the first pencil ("Edit Name") at the summary; the pencils, confirm and focus ring (3 px green-300, offset 3 Inside) follow visual order.
- **The chat card holds its geometry across widths and lenses.** Same 640 px card (715 at 390) with every bubble at 10 px rhythm, 280 px max bubble width, avatar and name block centred to 0.1 px (172.7 vs 172.6), the sun status dot centred on its label to 0.1 px, no horizontal page overflow at any width (docW = viewport).
- **Inside contrast for content is strong.** Body copy green-200 on green-950/900 reads 9.9–13.4:1, labels green-300 7.4–11.4:1, headings white 10–17:1; only the annotation notes fall short (HI-04).
- **Reduced motion is honoured end to end**: no reveal, no typing delay, no bubble rise, no grow animation; the chat answers in ~220 ms.
