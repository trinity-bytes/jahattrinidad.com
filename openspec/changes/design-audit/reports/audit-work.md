## 3. Patterns

- **Line height `normal` leaks into body copy.** WK-03 (pill height drifts 43/42/41), WK-04 (More body 1.28), WK-26 (problem facts, At a glance values). One cause: components that set `font` shorthand or rely on inherited `line-height: normal`. Fix once: `body { line-height: 1.5 }` and an explicit line height on every `font:` shorthand (buttons: `line-height: 1.25` + `min-height: 44px`).
- **Card and tile internals are not flex columns.** WK-05 (ragged action rows), WK-12/WK-13 (tile links wander), WK-22 (ragged formula tops). Make card, tile and step bodies `display: flex; flex-direction: column` with the action row or formula at `margin-top: auto`; then fixed heights (WK-01) become safe.
- **One role, two components.** "See the project →" (WK-03), back link (WK-20), kicker (WK-07), browser frame (WK-31), ↗ size (WK-30), h3 scale (WK-26). The Work index, the project page and the case study were built as separate views; a small shared set (CardAction, BackLink, Kicker, BrowserFrame) removes all six.
- **Glyphs where the system wants drawn icons or plain punctuation.** ★ ⑂ (WK-10), ● ● ● (WK-31), → in copy (WK-28). Icons from Lucide; arrows only on links.
- **Mono code does not inherit the brand mono.** WK-18 is one CSS line and fixes every code surface on the site.

## 5. Strengths

- Link arrows are right almost everywhere: every external link in the area carries the ↗ icon, `target="_blank"`, `rel="noopener noreferrer"` and the "(opens in a new tab)" note; internal "See the project" links carry `→` and stay in the tab.
- The peek opens on keyboard focus (`:focus-within`), is `aria-hidden` (no duplicate content for screen readers), is off on touch, and is instant under reduced motion.
- The TourBench table already uses `font-variant-numeric: tabular-nums` and lives in a real scroll wrapper; only alignment and the cue are missing.
- Tab order matches visual order on all three pages at all widths, and nothing in the area is focused under the fixed nav.
