### Restoring navigation

The navigation back stack did not survive process death. I fixed its restoration before closing the onboarding phase.

### A prototype is not a marketplace

The landing describes the complete exchange journey, but the Android plan still lists exchanges and chat as a future phase. The mock API keeps data on the device. A real shared backend and those remaining flows are needed before neighbours can actually exchange through it.

### The web prototype was replaced

The project previously included a web prototype. In October 2026 I removed it from the landing repository and focused on the native app instead. That meant leaving the earlier web implementation behind.
