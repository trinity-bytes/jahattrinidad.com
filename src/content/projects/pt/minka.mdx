### Restaurar a navegação

A pilha de navegação não sobrevivia à morte do processo. Corrigi sua restauração antes de encerrar a fase de boas-vindas.

### Um protótipo não é um mercado

A página descreve toda a jornada de troca, mas o plano Android ainda deixa trocas e chat para uma fase futura. A API simulada guarda os dados no dispositivo. Para conectar vizinhos reais, ainda faltam um backend compartilhado e esses fluxos.

### O protótipo web foi substituído

O projeto incluía um protótipo web. Em outubro de 2026 eu o removi do repositório da página para focar no aplicativo nativo. Isso significou deixar para trás a implementação web anterior.
