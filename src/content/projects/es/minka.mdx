### Restaurar la navegación

La pila de navegación no sobrevivía a la muerte del proceso. Corregí su restauración antes de cerrar la fase de bienvenida.

### Un prototipo no es un mercado

La página describe todo el recorrido de intercambio, pero el plan de Android todavía deja intercambios y chat para una fase futura. La API simulada guarda los datos en el dispositivo. Para conectar a vecinos reales faltan un backend compartido y esos flujos.

### El prototipo web fue reemplazado

El proyecto incluía un prototipo web. En octubre de 2026 lo retiré del repositorio de la página para enfocarme en la app nativa. Eso implicó dejar atrás la implementación web anterior.
